# Скриншоты

Все скриншоты обезличены:

- MAC-адреса, имена Bluetooth-устройств и SSID закрыты сплошной заливкой в цвет фона;
- порт helper скрыт;
- журнал диагностики в документацию не включён;
- строка состояния обрезана;
- имена и модель телефона не показаны.

Исходные скриншоты с реальными данными в репозитории не хранятся.
