# Активация и гибридный режим

## Что нужно один раз

1. Включить «Отладку по USB».
2. Включить «Отладку по Wi-Fi».
3. Открыть «Помощник точки доступа» → «Настроить помощника».
4. В настройках разработчика открыть «Отладка по Wi-Fi» → «Подключить устройство с помощью кода подключения».
5. Ввести 6-значный код в уведомление Hotspot Toggler и нажать «Отправить».

После этого ADB-ключ и порт сохранены. Повторное сопряжение по коду нужно только после «Забыть ADB-ключ» или сброса авторизаций ADB.

## Гибридный режим

```text
USB-отладка: ON
Wi-Fi-отладка: ON
        │
        ▼
helper запускается
        │
        ▼
Wi-Fi-отладку можно выключить
        │
        ▼
USB-отладка ON + helper работает
        │
        ▼
hotspot управляется по Bluetooth
```

Если helper остановился:

```text
Wi-Fi-отладка: ON
        │
        ▼
приложение находит сохранённый ключ и порт
        │
        ▼
helper запускается автоматически
        │
        ▼
Wi-Fi-отладку можно снова выключить
```

## Почему Wi-Fi-отладка нужна только для запуска

Приложение не может подключиться к USB-adbd: USB-adbd — это device-side интерфейс, к нему подключается только внешний ADB-хост. Приложение подключается к `127.0.0.1:<pair/connect port>`, который предоставляет Wi-Fi-отладка.

После запуска helper общение идёт по TCP-loopback и ADB больше не нужен. Но helper остаётся в cgroup adbd; поэтому USB-отладка должна быть включена, чтобы Android не остановил adbd и helper.

## Если helper остановлен

Приложение показывает:

- «Помощник не запущен»;
- «Включите Wi-Fi-отладку на 1–2 минуты»;
- кнопку открытия настроек разработчика.

После включения Wi-Fi-отладки приложение автоматически:

1. находит актуальный порт через mDNS;
2. подключается по сохранённому ADB-ключу;
3. запускает helper;
4. показывает «Помощник работает. Wi-Fi-отладку можно выключить».

## Если активация не начинается

- Убедитесь, что Wi-Fi-отладка включена.
- После удаления ADB-ключа нажмите «Настроить помощника» — приложение откроет настройки разработчика.
- Откройте «Отладка по Wi-Fi» → «Подключить устройство с помощью кода подключения».
- Введите код в уведомление, не закрывая системное окно.

Прямой переход сразу на Wireless debugging на Nothing OS заблокирован системными настройками: `SubSettings` требует разрешения `LAUNCH_SUBSETTINGS`, а `DevelopmentSettingsActivity` игнорирует fragment extra. Поэтому открывается обычный экран Developer options.

## Back и возврат в приложение

Android не позволяет приложению перехватить Back внутри чужого Activity.

- Back с корневого Developer options возвращает в Hotspot Toggler, потому что настройки открываются в задаче приложения.
- Back с вложенного экрана Settings сначала возвращает на предыдущий экран настроек.
- Для быстрого возврата в уведомлении есть действие «Вернуться в приложение».

## После перезагрузки

Helper не переживает перезагрузку. После загрузки:

1. включите Wi-Fi-отладку на 1–2 минуты;
2. приложение запустит helper автоматически;
3. Wi-Fi-отладку можно выключить;
4. USB-отладку оставьте включённой.

## Забыть ADB-ключ

«Помощник точки доступа» → «Забыть ADB-ключ».

Приложение:

- останавливает helper;
- очищает сохранённый ADB-ключ и Keystore;
- сбрасывает paired/port;
- требует новое сопряжение по коду.

## Ограничения

- Без Wi-Fi-отладки нельзя запустить helper после перезагрузки.
- Без USB-отладки Android может остановить helper.
- Обе отладки выключены → helper остановится; уже включённая точка доступа продолжит работать.
