# Диагностика и типовые проблемы

## Где смотреть состояние

Настройки → Диагностика:

- разрешение Bluetooth;
- разрешение уведомлений;
- ADB-ключ;
- отладка по Wi-Fi;
- отладка по USB;
- помощник;
- статус точки доступа;
- журнал приложения.

Журнал можно скопировать или отправить.

## «Помощник не запущен»

Проверьте:

1. Включена ли отладка по Wi-Fi.
2. Включена ли отладка по USB.
3. Не отозвана ли авторизация ADB.
4. Не выключен ли экран во время активации.
5. Не блокирует ли прошивка `app_process`.

Если Wi-Fi-отладка выключена, включите её на 1–2 минуты — приложение запустит helper автоматически.

Если не помогло — «Помощник точки доступа» → «Перезапустить помощника».

## «Помощник недоступен»

Проверьте TCP-loopback helper:

```text
adb shell "echo '{\"token\":\"<token>\",\"cmd\":\"ping\"}' | nc ::1 <port>"
```

Токен и порт можно увидеть в настройках/диагностике или в `shared_prefs`. Не публикуйте токен.

## «Отладка по Wi-Fi выключена»

Это не ошибка, если helper уже работает:

- статус «Отладка по Wi-Fi: Не требуется»;
- «Помощник работает без Wi-Fi-отладки».

Если helper не работает:

- включите Wi-Fi-отладку;
- приложение запустит helper автоматически.

## «USB-отладка выключена»

USB-отладка нужна, чтобы Android не остановил adbd/helper. Включите её и перезапустите helper.

## «Неверный код или окно сопряжения закрылось»

- Откройте «Отладка по Wi-Fi» → «Подключить устройство с помощью кода подключения».
- Введите код в уведомление, не закрывая системное окно.
- Если окно закрылось, откройте его снова и повторите.

## Прямой переход в Wireless debugging не работает

На Nothing OS экран Wireless debugging нельзя открыть напрямую: `SubSettings` защищён разрешением `LAUNCH_SUBSETTINGS`, а `DevelopmentSettingsActivity` игнорирует fragment extra. Приложение открывает Developer options; выберите «Отладка по Wi-Fi» вручную.

## Back возвращает не в приложение

Android не даёт перехватить Back в Settings. Back с корневого экрана возвращает в приложение, с вложенного — на предыдущий экран настроек. Используйте действие «Вернуться в приложение» в уведомлении.

## Hotspot не включается

- Проверьте статус helper.
- Проверьте, что оператор не блокирует tethering.
- Проверьте, что включена передача данных.
- Посмотрите журнал: `startTethering result=...`.
- Если hotspot включён вручную, приложение не будет считать его своим и не выключит после отключения Bluetooth.

## Hotspot не выключается после отключения

- Проверьте настройку «Выключать точку при отключении».
- Проверьте задержку (0–120 секунд).
- Приложение выключает только hotspot, который включило само.

## Приложение не видит Bluetooth-устройство

- Выдайте разрешение «Устройства рядом».
- Устройство должно быть сопряжено в системных настройках.
- Обновите список, открыв диалог выбора заново.

## Журнал содержит старые ошибки

Журнал очищается при обновлении приложения. Кнопка «Очистить» в диагностике очищает его вручную.

## Полезные команды

```text
adb shell dumpsys bluetooth_manager | grep -i <mac>
adb shell dumpsys tethering
adb shell dumpsys notification --noredact
adb logcat | grep -E "HotspotToggler|HotspotHelper|HotspotOps"
```
