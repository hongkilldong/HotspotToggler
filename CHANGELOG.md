# Changelog

## 1.0 — 2026-11-17

Первый публичный релиз.

### Возможности

- Выбор Bluetooth-устройства-триггера.
- Автоматическое включение точки доступа при подключении.
- Автоматическое выключение точки доступа после отключения с задержкой.
- Статус hotspot, SSID, интерфейс, клиенты, интернет.
- Общая скорость и график.
- Диагностика и журнал.
- Тёмная/светлая/системная тема.

### Доступ к tethering

- Helper через shell UID 2000 и `ITetheringConnector`.
- Сопряжение через отладку по Wi-Fi.
- Гибридный режим: Wi-Fi-отладка только для запуска/перезапуска helper, USB-отладка удерживает adbd.
- Автоматический перезапуск helper при включении Wi-Fi-отладки.
- Helper запускается из копии APK и переживает обновления приложения.

### Исправления

- Удалён ложный текст о том, что Wi-Fi-отладку можно выключать постоянно.
- Исправлено определение подключения Bluetooth-устройств на Android 16 без `BluetoothDevice.isConnected(int)`.
- Исправлено зависание авто-выключения из-за повторного запуска таймера.
- Исправлен устаревший порт ADB и ошибка `CERTIFICATE_UNKNOWN`.
- Уведомление с кодом сопряжения теперь видно в шторке.
- Убрана автогруппировка уведомлений, скрывавшая код.
- Кнопки ручного ввода и настроек разработчика получили нормальную высоту.
- Добавлен диалог выбора Bluetooth-устройства.
- «Доступ к точке доступа» переименован в «Помощник точки доступа».
- Добавлено действие «Вернуться в приложение» в уведомление.
- Журнал очищается при обновлении приложения.
